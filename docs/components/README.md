# Components Documentation

See `design-system/components.md` for the shared UI primitive
catalogue. This folder documents feature-level composed components as
they're implemented (populated during Phases 7–14), e.g.:

- `CourseCard`, `CourseForm`
- `LessonList` (drag-and-drop reorder), `LessonForm`, `VideoPlayer`
- `StudentTable`, `StudentProgress`
- `QuizBuilder`, `QuestionEditor`, `QuizTaker`
- `FileUploader`, `FileList`

Each entry, once implemented, documents: props, i18n keys used, and
RTL/theme considerations specific to that component.
